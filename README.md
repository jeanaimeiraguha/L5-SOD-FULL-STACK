# Product Management System

A full CRUD (Create, Read, Update, Delete) product management system built with React for the frontend and Node.js with MySQL for the backend.

## Features

- **Product Management**: Create, Read, Update, and Delete product records.
- **Frontend**: React application for managing product details.
- **Backend**: Node.js API with MySQL database for storing and managing product information.

## Technologies Used

- **Frontend**:
  - React
  - Axios (for API requests)
  
- **Backend**:
  - Node.js
  - Express
  - MySQL
  - JWT Authentication (if required)
